# 1.0.1 验证记录

本版本集中修复截图历史设置崩溃、截图与文字识别的界面阻塞、滚动截图内存和异步任务生命周期、录屏启动与停止的竞态，以及应用重复启动问题。

普通输入框选词的实际场景已由用户确认划词栏弹出。微信聊天消息场景在运行日志中两次记录到选区读取成功、划词栏显示；日志不包含消息正文。

本地 Release 配置运行 226 项测试，0 失败。Apple 原生翻译语言对测试会在系统缺少对应语言资源时跳过。测试覆盖截图历史和剪贴板顺序、输入框与密码框区分、微信选词、滚动截图拼接、翻译任务取消和进程级单实例。

界面短时验证覆盖设置中的截图保留数量调整、截图选区与取消、各主页面切换。长时间录屏、多显示器和真实网页滚动截图的压力测试尚未完成。
