# SnapLex：多 agent 阅读、电脑 agent 逐控件实测计划

日期：2026-10-25（Asia/Taipei）
对象：当前工作区源码与最终打包的 macOS 原生 SnapLex。
性质：执行计划与控件覆盖规范；本文件不是全量测试通过报告。

## 1. 交付目标

让 agent 像真实使用者一样打开应用、点击每一个可达按钮、展开每一个菜单、切换每个设置值、使用快捷键、绘制标注，并核对页面、剪贴板、文件和录制成片的实际结果。点击成功、路由单测通过、构建成功都不能单独算该功能通过。

范围包括五个主页面、状态栏面板、划词条、翻译卡片、截图覆盖层及其子栏、贴图及右键菜单、OCR 抽屉、滚动截图、录屏和系统保存对话框。非按钮交互如拖选、调整柄、滚轮、键盘、窗口焦点也要覆盖。

下列三个并行源码审查附件提供逐控件入口、步骤、断言和源码位置，是本计划的组成部分：

- [主界面、设置、历史与快捷键](audits/dashboard-settings-audit.md)
- [截图、标注、贴图、长截图与录屏](audits/capture-pin-record-audit.md)
- [划词、翻译、时序与运行环境](audits/translation-runtime-audit.md)

不把“足够复杂”理解为无限穷举。先对全部可达控件完成基础操作，再对危险状态、异步竞态及高风险组合加深；用覆盖账本而不是测试数量证明完整度。

配套 [414条初始用例账本](agent-desktop-case-ledger.csv) 已展开有限选项和独立入口，含操作、预期、等待预算、清理及证据字段，全部初始为“未验证”。执行时复制到该run目录，补充实际观测后才能改状态。附件内的编号是各审查报告的局部索引；统一追踪使用CSV的 `case_id`，避免把附件同名编号混为一条。

## 2. agent 分工与桌面互斥

| 角色 | 工作 | 可否操纵同一桌面 |
|---|---|---|
| 主 agent／执行者 | 掌握全局清单；通过电脑工具做实际操作；记录执行结果 | 是，唯一操作者 |
| 审查 agent A | 导航、历史、设置、快捷键；复核对应证据和漏项 | 否 |
| 审查 agent B | 截图、标注、贴图、滚动截图、录屏；复核输出 | 否 |
| 审查 agent C | 翻译、权限、焦点、时序、隔离；复核事件与结果 | 否 |

源码阅读与已保存证据的复核可以并行。当前同一台 Mac 的鼠标、键盘、剪贴板、前台窗口、系统权限属于共享资源，不允许多个 agent 同时操作。只有不同的独立 macOS 测试机／虚拟机才能并行执行 UI 批次。

执行批次交接必须包含：当前应用身份、页面和窗口、模式、剪贴板 fixture 类型、残留录屏/覆盖层/贴图、已改设置、下一条 case。未交接前不得由第二个 agent 接管桌面。

本项目是 macOS 应用；ARTEMIS 的 Android 设备探索不适用。本轮使用用户指定的“电脑”工具。若日后新增 Android 测试，应另按 AGENTS.md 先用 ARTEMIS 探索再编写测试，不能把本计划当成移动端交互证据。

## 3. 执行前环境门槛

### 3.1 保存构建身份

记录 git HEAD、工作区差异摘要、源码与 app 构建时间、二进制摘要、bundle ID、签名状态、macOS 版本、屏幕分辨率/缩放/排列、当前语言与外观。本仓库已有大量本地改动，不覆盖、不回退。当前源码与已有 dist 包是否一致必须单独查明。

正式批次从最终 app 包启动；必要时重新构建一个测试副本。保存构建、签名校验和相关已有测试结果作为前置证据，不能把旧文档中的通过数当成本轮结果。

### 3.2 数据、偏好与系统状态分别隔离

1. 优先使用专用 macOS 测试账户／虚拟机，仅展示合成内容。测试副本使用独立 bundle ID，并验证其偏好域实际独立。
2. 历史目录使用 `SNAPLEX_ISOLATED_TEST_DATA_ROOT`；它必须位于 `FileManager.default.temporaryDirectory` 解析后的子目录。不要凭经验写 `/tmp`，不要假设改 HOME 能隔离应用。
3. 启动后检查实际 SQLite 和截图路径，界面 0 条数据仅为辅助证据；注入一条哨兵数据并验证它只出现在测试目录。
4. 这个环境变量只重定向历史 Store。`UserDefaults.standard`、TCC、登录项、全局快捷键、系统剪贴板、默认打开图片应用仍需另外隔离或保存/恢复。
5. 日常实例与测试实例不能同时监听相同全局热键。批次前确认唯一监听者，避免把热键冲突误报为功能故障。
6. 所有保存/覆盖使用该 run 的专用输出目录。记录、删除、清空、保留上限测试只操作已标记的合成数据。
7. 权限首次申请、拒绝、撤销、麦克风授权、登录项真实生效，在专用环境完成。需要额外敏感权限时按电脑工具要求处理；不要在日常账户撤权来制造失败。

隔离尚未核实的批次只允许页面勘察和无副作用的菜单展开；删除、清空、调整保留数量、改变快捷键等依赖隔离的 case 保持“未验证”，不冒充通过。

### 3.3 固定 fixtures

| 编号 | 合成材料 | 验证目的 |
|---|---|---|
| F01 | 本地只读正文：`Selection test: The quick brown fox jumps over the lazy dog.` | 划词、复制、翻译、上下文 |
| F02 | 同页普通输入、多行编辑、密码框、contenteditable；预填 `DO-NOT-CHANGE-42` | 输入保护、焦点、快捷键 |
| F03 | 已知尺寸图片：棋盘格、可读编号文字、7 色块、四角方向标、透明区域 | 裁切、取色、马赛克/模糊、旋转/镜像、输出内容 |
| F04 | 肖像/物品、无主体风景、透明 PNG | 主体提取与背景虚化 |
| F05 | QR 与条码，payload 为 `SNAPLEX-TEST-20261025`；另有多码/无码/模糊码 | 扫码精确断言 |
| F06 | 本地长页：001–300 编号行、左右色标、固定顶栏、每屏唯一标记 | 长截图漏行/重复/拼接 |
| F07 | 动画时钟、移动方块、可控点击与按键、短测试提示音 | 录屏时长、暂停、指针、声音和音画同步 |

## 4. 电脑操作规范与完成定义

### 4.1 每个 case 的闭环

1. 观察：读取当前 AX 树和必要截图，核对应用身份、窗口、页面、前台与选区。
2. 定位：优先当前 AX 的可辨识控件；AX 无标签或画布无控件时，使用最新截图定位坐标，并记录窗口尺寸和位置。
3. 操作：执行一个语义动作，或一段不能被模型延迟打断的确定性动作；不能用内部函数调用替代点击。
4. 再观察：操作后刷新 AX。坐标不能跨布局变化复用；AX 索引不能跨刷新臆用。菜单弹出后重新获取菜单项。
5. 等待结果：检查状态条件，而非只等固定秒数。达到等待预算仍无结果，记录超时及最后状态；不无限重试。
6. 断言：至少验证一个可见结果和一个相关副作用（如文件内容/条数/焦点/窗口数量/无重复输出）。无副作用控件验证其明确 UI 状态。
7. 保存证据、复核、清理、进入下一条。不能跳过失败后悄悄按成功路径继续。

一条 case 最多做一次诊断性重试：先保存首次失败，恢复同一起点再试。第二次成功只标“首次失败、重试通过，待解释”，不能抹掉波动。

### 4.2 时间预算

| 操作 | 计划观察预算 | 到期处理 |
|---|---|---|
| 导航/菜单/普通按钮 | 5 秒 | AX+截图，判断未响应或窗口变化 |
| 截图覆盖层/贴图/恢复窗口 | 10 秒 | 核查权限、焦点、残留窗口 |
| OCR/扫码/图像效果 | 30 秒 | 保存忙状态/错误与样本 |
| 联网翻译/更新检查 | 30 秒 | 分开记网络超时与产品恢复 |
| 小型 MP4/GIF 导出 | 60 秒 | 持续观察导出状态，保存诊断 |

这是测试 watchdog，不是产品性能合格线。工具调用和模型思考耗时不记成应用渲染延迟。性能须单列同一种观测方式的基线。

双击 ⌘C 的判定窗口最多约 0.60 秒、重复选区抑制约 0.8 秒、内部复制抑制约 1.0 秒。两个快捷键应在同一次电脑调用中连续发送，并有实际间隔证据；不能把跨工具往返的两次按键当成有效双击测试。电脑工具不能证明间隔时，该边界仍未验证。精确边界由已有确定性逻辑测试补充，UI 负责验证真实事件链。

### 4.3 覆盖账本

每条记录有下列字段，统一写到 run 的 `cases.csv` 或等价 JSON：

`case_id, control_id, surface, entry, precondition, fixture, steps, expected_ui, expected_effect, wait_condition, timeout_s, status, evidence, issue, cleanup`

- 状态只允许：通过、失败、未验证、不适用。不适用要写原因和可达性依据。
- 动态重复行（如每条截图）按控件模板+首/中/末/空样本覆盖，账本另记实际实例；有限选项（7语言、12快捷键、10工具）逐个展开，不以抽样替代。
- 工具栏、菜单和快捷键即使调用相同底层动作，也分别计入口覆盖。
- 一组 case 涉及多个按钮时，每个按钮必须有自己的控件 ID 和证据映射，不能一个“截图已测”覆盖整个工具栏。
- 来源已静态列出但 UI 未出现的控件记“待发现”；确认无正常入口才记“不适用/不可达”。不存在的按钮不虚构。

覆盖率分别报告：已发现可达控件／静态候选、实际操作控件／已发现可达控件、通过 case／已执行 case、关键状态转换覆盖。未验证、不可达和失败单独列出。

## 5. 分批执行清单

下面 ID 是稳定模块前缀；具体按钮和值按三个附件展开为独立 case。所有行均是待执行要求，不是通过记录。

### B0：勘察、启动与退路

| case | 操作 | 必须核对 |
|---|---|---|
| ENV-01 | 隔离实例冷启动 | bundle、路径、偏好域、唯一热键监听者、0数据与哨兵数据 |
| ENV-02 | 菜单栏开/关/外点关闭；打开主窗口 | 单一面板；没有遮挡或重复实例 |
| ENV-03 | 红色关闭、最小化、放大、拖动、Dock/状态栏重开 | 后台仍活、窗口可恢复；最小尺寸1080×720布局可读 |
| ENV-04 | ⌘Q、⌘,、Esc分别使用 | ⌘Q为隐藏主页；⌘,到偏好；记录Esc所处焦点 |
| ENV-05 | 菜单展开时Esc、保存面板Esc、录制倒计时Esc | 分别验证菜单/模态/主窗的退出优先级 |
| ENV-06 | 最后点击状态栏电源退出，再重启 | 进程、状态栏、监听和伴随窗口全部结束，数据可恢复 |

### B1：全部普通窗口控件

- `NAV-*`：5个导航逐个点击、重复点击、任意两页往返；首页“立即截图”和3个快捷操作；最近截图、今日高频词、最近翻译的3个跳转；4个预览实例。
- `MENU-*`：状态栏顶/底两个控制台入口、截图/录屏/贴图3入口、截图查看全部、3个最近截图行、翻译记录、电源。顶部与底部相同功能仍独立点击。
- `HIST-*`：4日期×2视图；单项删除、清空取消/确认；忽略词入口、输入、加号、Return、移除、完成；单条重复词、重复大小写/重音词、删除后图表与词频联动。
- `SHOT-HIST-*`：刷新、清空取消/确认、缩略图单击、右键打开、Finder显示、右键删除、卡片垃圾桶；空态禁用、缺文件、损坏文件和重启后结果。
- `PREF-*`：3外观、7语言、2引擎；5个开关分别开/关（鼠标、双复制、登录项、划词记录、截图记录）；AX状态刷新与条件授权入口；保留数量增减两个按钮；两个历史跳转；检查更新与条件发布页链接。
- `KEY-01..12-*`：每一行单独进入录制、再次点击取消、Esc取消、有效改绑、实际触发、重启后保持、恢复默认；代表行补冲突、无修饰字母、保留编辑键；录制中切页/换行/关窗/恢复默认。

具体数据断言按源码语义：状态栏是最近24小时，首页是今日；“近一月”与“近30天”不等价；单条记录相同词最多计一次；词频列表最多100项。不可把这些差异直接判成bug。

保留数量当前范围1–1000、步长10；必须核对靠边界时真实步进、是否越界、淘汰哪张和文件是否同步删除。降低上限是会删除旧截图的操作，只在合成数据环境执行。

### B2：划词与翻译真实链路

1. `SEL-*`：只读浏览器正文、链接文字、只读PDF；单词/整句/多行/emoji/中英混合；拖选与双击；上下文、输入原文和浮条位置正确。
2. `SEL-SAFE-*`：普通输入、多行编辑、密码框、contenteditable中选中；不得自动弹条或改写内容。测试前后逐字符比较 `DO-NOT-CHANGE-42`，剪贴板外部变化与内部复制分别记录。
3. `SEL-STATE-*`：鼠标/双复制开关四组合、无选区、空白、快速新选区、切前台应用、右键打断、截图覆盖层已开、浮窗位于选区上方。旧AX结果不能覆盖新手势。
4. `PILL-*`：Logo、翻译、复制、朗读分别操作；复制须在测试输入框粘贴核对原文；朗读核对原文且无额外翻译记录。当前没有截图/设置/关闭按钮，不按旧接口臆测控件。
5. `CARD-*`：目标语言7项逐一、固定/取消固定、关闭、原文对照开关、系统词典开关、朗读、复制、2引擎菜单、重译；各在空/加载/成功/失败状态选相关组合。源语言展示是标签，不能计划点击切源语言。
6. `CARD-ASYNC-*`：请求A后发B、旧结果晚到；加载中改目标/引擎/重译/关闭；关闭后不得重开；重开接收新请求。无可控故障设施时先做自然触发并如实记不可验证的顺序。
7. `CARD-HIST-*`：真正划词与截图翻译在记录开/关时分别核对；手动卡片 `.manual` 不记录是当前实现，不能要求所有翻译都加历史。

通过真实跨应用划词必须同时有选区、对应的系统鼠标事件链（若有可用诊断）、AX接受与浮条/结果证据。电脑工具只改变了选区而没有足够事件证据时，不宣称验证物理鼠标路径；更不能改用其他系统输入注入工具偷偷替代电脑工具。

### B3：截图覆盖层与23个主控件

- `CAP-ENTRY-*`：首页立即截图、首页快捷操作、状态栏、F1、备用快捷键各走一遍→取消→重新进入。取消前和取消后都检查覆盖层/工具栏/放大镜是否释放。
- `CAP-REGION-*`：窗口识别、四向拖选、8个调整柄、整体移动、屏幕边缘、方向键1px与Shift10px；7/8px截图门槛和31/32px录屏门槛；已知色块放大镜与C复制颜色。
- `CAP-TOOL-*`：矩形、椭圆、直线、箭头、画笔、荧光笔、马赛克、模糊、序号、文字，各完整画一遍；另外实际点撤销、重做、长截图、录屏、翻译、提取文字、背景虚化、提取主体、扫码、贴图、保存、取消、完成复制，共23主控件。
- `CAP-STYLE-*`：2/4/8线宽、矩形/椭圆空实心、7颜色、文字粗体/斜体/字号减加；字号10和120边界；空文字、中文、英文、emoji、长段落。
- `CAP-ANN-*`：每个工具创建→取消选中→再次命中→移动→缩放→旋转（仅对支持对象）→撤销→重做→导出检查。连续新建、撤销后另建清空redo、空历史禁用分别测试。
- `CAP-OUTPUT-*`：按钮完成、Enter、小键盘Enter、双击、保存、⌘S、贴图、F3/⌘T各独立入口；输出内容、尺寸、标注及历史数量核对。保存取消前可能已记录截图，先依实现记录副作用，不能预设无历史。
- `CAP-VISION-*`：有/无主体；有/无文字；QR/条码/多码/无码/模糊码；成功与失败后继续截图；输出 payload 精确核对。

### B4：贴图、OCR与隐藏菜单

- `PIN-INPUT-*`：来自截图、剪贴板图片、文字、色值、空剪贴板；只使用合成内容。
- `PIN-BAR-*`：缩小、放大、1:1、90°旋转、背景虚化、提取主体、标注、翻译、OCR、阴影、穿透、复制、保存、关闭，共14主控件。
- `PIN-ANN-*`：贴图画布10工具、撤销、7色、文字粗斜体与字号；另测键盘redo。截图和贴图是两套绘制实现，必须分别验证输出。
- `PIN-CONTEXT-*`：右键原位翻译/还原、OCR、标注、复制、保存、旋转、水平镜像、阴影、折叠/展开、穿透、关闭，每项实际选中。不要只测工具栏同名按钮。
- `PIN-TRANSFORM-*`：滚轮缩放15%–400%、Option滚轮透明度15%–100%、0复位、四次旋转、两次镜像；折叠54×54→拖动→展开，核对尺寸位置与输出。
- `PIN-PASS-*`：穿透后点击下方F02，确认交互落到下层；独立“退出穿透”按钮恢复；四角、缩放、多个贴图时均可找回。不能因图片无法点击而遗留穿透。
- `PIN-OCR-*`：开抽屉、看原文/译文条件按钮、编辑、复制全部、关/重开；翻译中还原/关闭/图像效果变化与缓存失效。
- `PIN-RESTORE-*`：A/B/C关闭恢复、最近25上限与第26个、解锁所有；每次核对伴随工具栏/抽屉/穿透按钮。无正常UI入口的管理方法仅记录源码存在，不虚构按钮。

重点观察：当前贴图马赛克/模糊的绘制代码有灰色矩形风险；用可读文字与棋盘格在屏幕和保存图片上检查。恢复关闭贴图可能只保留原图和frame，需记录标注、旋转、透明度是否丢失，再对照产品约定定级。静态风险不能直接记已复现bug。

### B5：长截图

1. `SCROLL-01`：F06下滚5屏→上滚2屏→继续到新内容→完成；编号连续、无遗漏/重复、宽度与比例正确。
2. `SCROLL-02..07`：自动滚动→按钮停止→继续；Space暂停；移出选区暂停；点击暂停；每条独立恢复再测，核对按钮文案与状态。
3. `SCROLL-08..12`：页底/页顶、静态不可滚、快速惯性、横向漂移、窗口遮挡；不把未移动帧无限追加。
4. `SCROLL-13..16`：按钮完成/Enter、按钮取消/Esc；完成后剪贴板、贴图、截图历史三方核对；取消后无残留控制面板/定时滚动。
5. `SCROLL-17`：马上再开一次，预览和计数归零，旧会话不继续作用于旧窗口。

### B6：录屏与成片

- `REC-MODE-*`：区域/窗口/全屏各完整录制；窗口列表中选与直接点窗口；切模式后选区、窗口数量与指示器核对。
- `REC-DELAY-*`：0/3/5秒逐项；倒计时中结束与Esc；倒计时前后重复开始不得创建并行pipeline。
- `REC-OPTION-*`：指针、点击波纹、按键显示、系统音、麦克风，每项开/关分别录出能区分结果的F07成片；系统/麦克风音独立与同时开启均覆盖。音频需检查轨道并听合成提示音。
- `REC-PAUSE-*`：录3秒→暂停2秒→续录3秒→结束；计时、视频片段和音画同步核对。按钮、F10、Esc结束各独立测试；录制中截图后能否继续。
- `REC-EXPORT-*`：MP4/GIF逐项；改名、切格式后缀、新建目录、保存、取消、测试文件覆盖取消/确认；导出内容实际打开，核对尺寸/时长/方向/帧序列/音轨，GIF不要求音轨。
- `REC-STATE-*`：录制中再录、导出中再录、零有效帧、保存失败恢复；窗口模式录制时移动和遮挡窗口，明确它是固定显示区域裁切还是跟随窗口，不预设跟随。

精确暂停时长需要有可信计时证据。模型思考间隔不能当3秒/2秒计时；不能稳定控制时只验暂停状态，精确时长另由录制fixture时间戳或专用测试设施验证。

## 7. 视觉、规模与连续操作

有限选项完整覆盖；组合采用关键全交叉+其余两两组合，不做7语言×所有模式的无意义笛卡尔积。

- 外观：系统浅/深×应用跟随/浅/深6种，在专用环境实际截图；五页面、状态栏、翻译条/卡片、截图子栏、贴图抽屉均覆盖代表状态。
- 语言：7种都实际选择并检查五页和主要弹窗；简中/英文/德文深入到所有浮窗、菜单、错误与最小尺寸。
- 尺寸：最小/默认/最大窗口；翻译1/10/11行与超长文本；截图1×1等不可用尺寸、窄条、超宽；Retina与多屏不同缩放在可用测试机上验证，无设备写未验证。
- 数据量：历史0/1/100/1000；截图各UI上限3/4/100边界。观察滚动错图、计数刷新和内存，实际数据来源标明。
- 连续操作：先20轮固定序列（切页→截图→标注→取消→开翻译卡片→切引擎→关闭→状态栏→贴图→关闭恢复），再30分钟有界混合操作。每步保存case ID和输入序列；中途失败暂停序列，保留现场。
- 长测每5分钟记录一次窗口数、进程存活、内存趋势与已完成操作数。不在没有基线时凭一次高内存定泄漏。
- 休眠唤醒、显示器拔插、Spaces/全屏应用、权限首次拒绝属于专用环境批次，不能为了完成数量随意改变日常机器状态。
