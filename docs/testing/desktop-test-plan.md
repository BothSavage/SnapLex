# SnapLex macOS 测试计划

版本：2026-10-25
范围：划词触发与输入安全、翻译卡片与服务恢复、页面按钮与系统权限/窗口流程。

## 目的与测试层级

本计划把可重复的本地逻辑测试和必须在 macOS 桌面上验证的行为分开。测试分为四层：

| 层级 | 验证内容 | 建议方式 | 能证明什么 |
|---|---|---|---|
| L0 策略 | 纯输入/输出规则、格式、边界 | XCTest，固定输入和时钟 | 策略对给定参数作出预期判断 |
| L1 服务 | 网络请求、解析、错误映射、存储 | XCTest + `URLProtocol` / fake 服务 / 临时目录 | 服务代码在模拟响应和故障下的行为 |
| L2 状态与界面动作 | ViewModel 状态转移、按钮动作路由、偏好持久化 | XCTest + 注入依赖；必要时 SwiftUI/AppKit 宿主测试 | 应用代码触发了预期动作和状态更新 |
| L3 macOS 集成 | Accessibility、TCC、全局事件、系统面板、真实窗口焦点 | 隔离 macOS 账户/虚拟机和人工验收 | macOS 实际权限、事件分发和窗口交互能够工作 |

L0–L2 成功不等于端到端成功。任何会读取其他应用 AX 树、监听全局鼠标/键盘、写系统剪贴板、请求系统权限或打开非激活浮窗的链路，都必须保留 L3 验收。

### macOS 权限和窗口手工验收清单

每次发布候选版本至少在独立 macOS 用户或可还原虚拟机执行一遍。测试前确认测试账户可以撤销/重授以下 TCC 状态：

1. **屏幕录制/屏幕与系统音频录制**：首次拒绝时 F1 不得打开遮挡权限对话框的截图覆盖层；授权后再按 F1 能恢复；设置页离开/重开后状态更新。
2. **辅助功能**：分别用未授权、授予、撤销状态验证鼠标选区与双击 Cmd+C；没有权限时不能循环弹窗或冻结全局输入。
3. **全局快捷键与输入法**：确认自定义快捷键注册/冲突反馈；中、日、英输入法的编辑区域不能被全局选区触发破坏。
4. **窗口关闭语义**：关掉主页面只隐藏窗口；菜单栏图标和热键服务仍在。选退出才结束应用。逐一检查首页、设置、翻译历史、截图历史、翻译卡片、选区胶囊、截图覆盖层、录屏助手和 Pin 的 Esc/关闭行为。
5. **焦点**：弹出只读翻译卡片后继续在原应用打字；只有用户点击卡片编辑区时才获得文本焦点；点击外部、Esc 和关闭按钮按当前窗口状态正确释放。
6. **多屏与 Spaces**：主副屏、不同缩放、全屏桌面、Dock 自动隐藏、菜单栏摄像头凹槽区域检查浮窗锚点、裁边和 pin 工具栏位置。

真实 TCC 提示受系统缓存、App 签名/路径和用户授权状态影响，不能靠普通 XCTest 可靠复位；截图/录屏、AX 和全局键盘行为必须在隔离环境人工验收，自动化结果中记录 macOS 版本、显示器数量、权限状态与 App 构建签名。

## 执行与报告约定

- P0 每次提交或候选包必须覆盖；P1 在相关功能改动、每周集成或发版前覆盖；P2（后续新增）纳入回归矩阵。
- 自动化报告需列出测试层级、场景 ID 范围、OS 版本和是否使用 fake。策略组合通过只能报告为“策略测试通过”，不能写成“划词端到端通过”。
- L3 报告附带手工步骤、权限前置状态、实际结果和截图/日志位置；权限授权前后各执行一次。
- 扩展组合时优先固定所有安全关键拒绝路径，再扩大正常路径；异步竞态使用可控 continuation/时钟，不用真实 `sleep` 碰运气。
