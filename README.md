# SnapLex

**SnapLex** 是一款基于 **Swift + SwiftUI + AppKit** 原生构建的 macOS 截图与效率工具，支持贴图钉屏、长截图、ScreenCaptureKit 录屏、Vision 图像处理、OCR 和系统原生翻译。

---

## 核心特性

### 1. 极速截图、取色与标注 (`F1` / `⌥ + S`)
- **0 延迟瞬时响应**：后台常驻预热截图画布与单帧 GPU 纹理上传，按 `F1` 瞬间唤起。
- **智能窗口识别 + 8 控制点微调**：移动鼠标自动识别光标下的窗口边界，支持单击锁定窗口、自由拖拽框选、8 方向缩放微调及方向键 `1px` 像素级移动。
- **11×11 像素级放大镜与取色器**：选区阶段实时显示光标处像素网格与坐标，按 **`C`** 复制色值，按 **`Shift`** 切换 **`HEX` / `RGB` / `HSL`**。
- **全套专业标注工具**：
  - `矩形`、`椭圆`（空心/实心）、`直线`、`箭头`、`画笔`、`荧光笔`、`马赛克`、`高斯模糊`、`自增序号 ①②③`、`文字批注 (A)`。
  - **无背景直接文字批注 (`A`)**：点击画布直接输入文字（无弹窗、无背景底色），支持 **加粗 (`B`)**、**斜体 (`I`)**、**字号无级调整 (`- / +`)** 与多色切换。
  - 支持无限级 **撤销 (`⌘Z`) / 重做 (`⌘⇧Z`)**。
- **Vision + Core Image 图片效果**：可从截图工具栏提取透明背景主体，或保留主体并虚化背景。

### 2. 上下双向滚动长截图（实时预览）
- 在截图工具栏点击 **长截图** 按钮即可进入滚动长截图模式：
  - **支持向上 & 向下双向滚动拼接**：基于 Apple Vision `VNTranslationalImageRegistrationRequest` 二维相位相关与全重叠区边缘梯度校验（`Active-Edge MAD`），自动选取行间空白处无缝拼接。
  - **实时双栏预览**：右侧悬浮窗实时展示当前拼接段数与长图全览，支持手动滚轮/触控板滚动与一键 **自动滚动**（移出选框或按 `Esc` 随时停止，按 `Enter` 完成并自动贴图）。

### 3. 无边框阴影贴图 (`F3` / `⌥ + P`)
- **无边框 + 默认自然阴影 + 外围悬浮工具栏**：
  - 支持将截图、长截图、剪贴板图像、纯文本或 `#RRGGBB` 色值一键钉在屏幕顶层。
  - 外围纯黑工具栏支持 **0ms 悬停提示**，缩放贴图时锚点固定不跳动，方便连续放大/缩小。
- **原位 OCR 贴合翻译 (`[文A]`) & 右侧提字栏 (`[文]`)**：
  - 一键识别贴图内文字并原位替换为译文，或展开右侧可复制文本抽屉。
- **贴图实时批注 & 鼠标穿透 (Ghost Mode)**：
  - 贴图状态下同样支持全套图形与 `A` 文字批注；开启鼠标穿透后右上角保留一键解除胶囊按钮。
- **`⇧ + F3`**：恢复最近关闭的贴图窗口。

### 4. ScreenCaptureKit 屏幕录制（导出 MP4 / GIF）
- 在截图工具栏点击 **录屏** 展开纯黑子工具栏：
  - 支持 **区域录制（默认）**、**窗口录制（可直接点击屏幕上的打开窗口或从列表选择）**、**全屏录制（菜单居中显示）**。
  - 支持 `0s / 3s / 5s` 倒计时、系统鼠标指针与点击效果、按键回显、系统音频和麦克风。
  - 使用 ScreenCaptureKit 实时采集并写入 **H.264 MP4（默认，最高 30 FPS）**，避免把未压缩帧堆在内存中；也可从录屏生成循环 GIF。

### 5. 全局划词悬浮条与翻译记录
- **鼠标划词即弹胶囊条**：在任意应用中划选文本松开鼠标（或双击 `⌘C`）即可翻译、查词、复制或朗读。
- **系统原生翻译**：翻译通过 Apple Translation 框架完成；支持的语言模型由 macOS 管理，首次使用时系统可能会提示下载语言资源。
- **翻译记录与词频统计**：自动记录划词翻译和截图翻译，按时间范围查看翻译次数、单词频率及忽略词。

## 编译与运行

### 环境要求
- macOS 15.0 (Sequoia) 及以上
- Xcode Command Line Tools (`swift 5.10+`)

### 一键编译打包

```bash
git clone https://github.com/your-username/SnapLex.git
cd SnapLex
./scripts/build_app.sh
open ./dist/SnapLex.app
```

首次运行请在 **系统设置 → 隐私与安全性** 中授予 **屏幕录制**（用于截图/长截图/录屏）、按需授予 **麦克风**（录制麦克风音频），以及 **辅助功能**（用于全局快捷键与划词检测）权限。
